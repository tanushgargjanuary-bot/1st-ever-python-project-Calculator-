# Python Calculator

A beginner Python command-line calculator. It supports addition, subtraction, multiplication, and division.

## Run

Requires Python 3.

```bash
python "Calculator Code"
```

The program asks for an operation and two numbers. It then asks whether you want another calculation.

## Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Division-by-zero check
- Repeated calculations until the user exits

## Learning goals

This was an early Python project. It practises:
- Functions
- User input
- Conditional statements
- A `while` loop
- Basic arithmetic

## Limitations

- Invalid numeric input can stop the program.
- The calculator supports only two-number operations.
- It is a learning exercise, not a production calculator.
